## Tools

`repo/work/person_variants.sh`: `variant NAME BETA LAM [OTHER WEIGHT]...` builds a person-only variant on the CPU. The anchor frame never moves, so
CD-O stays exactly the same. `pipeline/recipes/pack_candidate.sh NAME` packs and refuses a commit that is not on the remote.
`scripts/submit_candidate.py` uploads. `scripts/object_transfer.py` carries objects from one person to another.
New small GPU steps queue behind the owner's other jobs. To run them at once while the CARI4D job lives, use:
`srun --jobid=<c4all job id> --overlap --ntasks=1 --cpus-per-task=10 --mem=80G bash -c '...'`.

## Lessons

- Local cross-checks predicted poorly: the floor slide's looked bad and it helped, and "objects too far" looked good and was false on
  average. Only Kaggle decides. Person and object effects can be read from one file while the anchor frame stays fixed.
- In `pgrep -f` and `pkill -f`, a pattern can match the shell running it. Use a script file or `-x`.
- Smooth MHR on the mesh, never on its Euler parameters.
